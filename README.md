# ML_Projects
All my learning code while taking the Google Machine learning course

## Projects

- [`robocraft/`](robocraft/): **RoboCraft**, an MVP of a web-based robotics builder.
  It is a 3D design studio for a robot arm and a rover. A FastAPI backend handles
  kinematics, torque sizing and safe-circuit generation, and writes Arduino/MicroPython
  firmware. See [`robocraft/README.md`](robocraft/README.md).
- [`tello/`](tello/): a gamepad and keyboard flight controller for the DJI/Ryze Tello
  drone, built with pygame and djitellopy. See [`tello/README.md`](tello/README.md).
